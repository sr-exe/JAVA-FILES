# ☕ Java Full Stack Journey

> A structured, hands-on journey from Core Java to Java Full Stack Development.

This repository documents my journey of learning Java from the fundamentals to full-stack development.

I'm not trying to memorize programs. My focus is on understanding **programming logic, problem-solving patterns, code organization, debugging, and gradually building real-world applications.**

---

## 🎯 Goal

Build a strong foundation in:

- Core Java
- Object-Oriented Programming
- Data Structures & Algorithms
- SQL & JDBC
- Spring Boot
- REST APIs
- Frontend Development
- Full Stack Development
- Git & GitHub
- Deployment
- Computer Science Fundamentals

Ultimately, the goal is to become **a Java Full Stack Developer**.
